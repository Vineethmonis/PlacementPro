# PlacementPro

PlacementPro is a campus placement management system developed to simplify the recruitment workflow within an institution.

It provides structured dashboards for students and placement officers to manage placement drives and application tracking efficiently.

---

## Features

### Student Dashboard
- View eligible placement drives
- Track application status
- Monitor profile completion
- Resume generation option

### Placement Officer Dashboard
- Secure login (role-based)
- Manage placement drives
- Monitor student applications

---

## Tech Stack

Frontend:
- HTML
- CSS
- JavaScript

Backend:
- Node.js
- Express.js

Database:
- MongoDB

Authentication:
- JWT-based login system

---

## Project Structure

- `admin_dashboard/` – Placement Officer interface
- `student_dashboard/` – Student interface
- `server/` – Backend API (routes, controllers, models)
